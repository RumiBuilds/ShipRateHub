# ShipRateHub

ShipRateHub is an Android application designed to help customers compare shipment rates, manage shipments, track deliveries, and view shipment history. It also provides shipping business owners with tools for customer management, invoices, profit calculation, and analytics.

## Features

### Customer Features

- Customer registration and login
- Shipment management
- Shipment rate comparison
- Rate result display
- Shipment history
- Shipment tracking
- User-friendly customer dashboard

### Owner Features

- Owner dashboard
- Customer management
- Shipment management
- Invoice management
- Profit calculation
- Business analytics

### Authentication

- User registration
- User login
- Role selection
- Customer and owner accounts

## Technologies Used

- Kotlin
- Android Studio
- Android SDK
- XML
- Firebase
- Firebase Authentication
- Firebase Database
- RecyclerView
- Android Activities & Adapters
- Gradle
